# Simple Inventory Tracker

## Project Overview
The Simple Inventory Tracker is an Excel-based project designed to manage inventory efficiently by monitoring stock quantities, reorder levels, and stock status.

## Objectives
- Track available inventory.
- Identify products requiring restocking.
- Automate stock status using IF formulas.
- Calculate inventory value and estimated reorder costs.

## Tools Used
- Microsoft Excel
- Excel IF formulas
- Conditional Formatting

## Workbook Sheets
1. **Inventory Tracker** – Product details, stock quantities, reorder levels, stock status and inventory value.
2. **Low-Stock Report** – Products requiring restocking, reorder quantities and estimated reorder costs.
3. **Read Me** – Instructions and formula explanations.

## Key Features
- Automatic stock status calculation.
- Low-stock identification.
- Conditional formatting for reorder items.
- Automatic reorder quantity calculation.
- Estimated reorder cost calculation.

## Skills Demonstrated
- Excel formulas
- Inventory management
- Data organization
- Conditional formatting
- Rule-based analysis

The workbook contains illustrative sample inventory data.
